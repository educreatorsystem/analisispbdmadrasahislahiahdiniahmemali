# Sistem Analisis PBD – MADRASAH ISLAHIAH DINIAH MEMALI

Versi asal sistem PBD tanpa PWA. Hanya konfigurasi Sheets/Apps Script, URL CSV, nama dan lencana sekolah dikemas kini.

## GitHub Pages
1. Muat naik `index.html` ke root repository GitHub.
2. Buka Settings > Pages dan pilih branch `main`, folder `/ (root)`.
3. Simpan dan buka pautan GitHub Pages selepas deployment.

Lencana: https://iili.io/nrddBON.jpg

**Nota:** Pemaparan data dan fungsi simpan memerlukan sambungan Google Sheets serta Apps Script yang dibenarkan dan berfungsi. Akses rangkaian belum diuji.
